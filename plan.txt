[빌리언 체험단 사이트 기획서]

1. 회원 기능
- 회원가입
- 로그인
- 마이페이지
- 내 신청 내역
- 선정 여부 확인
- 리뷰 작성 상태 확인

2. 체험단 기능
- 체험단 목록
- 카테고리별 보기
- 체험단 상세페이지
- 체험단 신청하기
- 신청 완료 확인

3. 업체 기능
- 업체 회원가입
- 캠페인 등록 신청
- 제공 내역 입력
- 모집 인원 입력
- 리뷰 미션 입력

4. 관리자 기능
- 체험단 등록
- 신청자 확인
- 선정자 관리
- 공지사항 등록
- 캠페인 마감 처리

5. 나중에 추가할 기능
- 블로그 지수 입력
- 인스타 팔로워 입력
- 선정 알림
- 리뷰 URL 제출
- 리뷰 승인
- 포인트 또는 등급제
